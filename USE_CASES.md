# Jev Use Case Catalogue

Jev by TypeSafe AI is a calibrated zero-shot semantic classifier trained via RLCD. It takes arbitrary text `state` (context) and dynamically defined `criteria` (questions) to return a calibrated probability simplex over that criteria space in ~50-200ms. 

**Core primitives:**
- `choice`: Pick from a criteria dictionary. Returns probabilities.
- `score`: Ordered rubric array. Returns probabilities over levels.
- `noul`: Boolean probability. Returns likelihood of truth based on instructions.

Total Use Cases: 120
